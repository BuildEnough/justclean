# 저스클린 랜딩페이지

청소업체 **저스클린**을 소개하기 위한 React 기반 랜딩페이지.
고객이 업체 정보를 빠르게 확인하고, 작업 과정과 전후 사진을 통해 신뢰감을 느낄 수 있도록 제작했습니다.

## 프로젝트 소개

저스클린은 건식 작업, 습식 작업, 살균 소독, 장비 전문 케어를 제공하는 청소 전문 업체입니다.

이 프로젝트는 실제 운영 중인 청소업체의 홍보용 웹페이지를 목적으로 제작했으며, 단순한 소개 페이지가 아니라 고객이 상담까지 이어질 수 있도록 다음 요소를 중심으로 구성했습니다.

- 업체 소개
- 주요 서비스 안내
- 작업 과정 설명
- 작업 전후 사진
- 공식 채널 연결
- 전화 / 문자 / 네이버 플레이스 상담 연결

## 주요 기능

### 1. 메인 대표 이미지 슬라이드

상단 Hero 영역에 대표 이미지 6장을 자동 슬라이드로 보여줍니다.

- 3.5초마다 자동 전환
- 하단 점 버튼으로 이미지 직접 선택 가능
- 배경 이미지 적용으로 시각적 완성도 향상

### 2. 주요 서비스 소개

저스클린의 주요 서비스를 카드 형태로 구성했습니다.

- 건식 작업
- 습식 작업
- 살균 소독
- 장비 전문 케어

### 3. 작업 과정 안내

고객이 청소 진행 흐름을 쉽게 이해할 수 있도록 작업 과정을 순서대로 정리했습니다.

```text
현장 방문 → 장비 세팅 → 오염도 체크 → 건식 작업 → 습식 작업 → 살균 소독 → 청소 완료
```

### 4. 작업 전후 사진

청소 결과를 직관적으로 보여주기 위해 Before / After 사진 영역을 구성했습니다.

- 오염 제거 전후
- 생활 오염 클리닝 전후
- 공간 케어 전후
- 부분 오염 집중 케어 전후
- 습식 클리닝 전후
- 마무리 케어 전후

### 5. 공식 채널 연결

고객이 다양한 경로로 업체 정보를 확인할 수 있도록 외부 채널 링크를 연결했습니다.

- 네이버 블로그
- 네이버 플레이스
- 당근 프로필
- 인스타그램

### 6. 상담 연결

모바일과 PC에서 바로 상담할 수 있도록 버튼을 배치했습니다.

- 전화 상담
- 문자 상담
- 네이버 플레이스 이동

### 7. 이미지 보호 처리

웹에서 이미지를 쉽게 저장하지 못하도록 기본적인 보호 처리를 추가했습니다.

- 이미지 우클릭 방지
- 이미지 드래그 방지
- 이미지 선택 방지
- JUST CLEAN 워터마크 오버레이

## 제작 목적

이 프로젝트는 단순 학습용 페이지가 아니라, 실제 청소업체를 소개하고 상담 연결까지 이어질 수 있도록 제작한 실사용 목적의 랜딩페이지입니다.

특히 다음 부분에 중점을 두었습니다.

- 모바일에서도 보기 좋은 반응형 UI
- 작업 전후 사진 중심의 설득력 있는 구성
- 상담 버튼을 통한 빠른 고객 연결
- GitHub Pages를 활용한 정적 사이트 배포
